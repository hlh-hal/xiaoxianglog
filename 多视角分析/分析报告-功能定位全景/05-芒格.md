# 芒格视角：35个功能的多元思维模型审计

> "反过来想，总是反过来想。如果知道我会死在哪里，我永远不去那个地方。"

---

## 一、核心假设：你在做什么生意？

日记App的**真实生意**是：**把人留住，让他每天都来写**。

不是社交，不是AI，不是排行榜。是**习惯**。
一个用户愿意每天打开你的App写15分钟——这就是全部护城河。

所有不服务于"让人来写"的功能，都是在**消耗注意力和开发资源**。

## 三、用芒格的12条思维模型审视

### 模型1：反转思维（Inversion）
> 不要想"怎么让它成功"，先想"什么会杀死它"。

**会杀死小象日志的不是功能少，是功能多到让人觉得这不是"我的日记本"。**
社交功能（Community/Friends/Inbox/Leaderboard/PostDetail）会把产品拖进和微信、小红书的竞争——你永远打不过。

### 模型2：能力圈（Circle of Competence）
> 你真正懂什么？

小象日志的核心能力是**帮助人记录和理解自己**。社交运营、社区治理、IM系统——都不是日记团队的能力圈。每多一个社交功能，就离能力圈远一步。

### 模型3：激励机制（Incentives）
> 什么在真正驱动用户？

用户来写日记的动机：**记录、反思、治愈、仪式感**。
Leaderboard把动机扭曲成"比谁写得多"——这是**外在激励摧毁内在动机**的经典案例。

### 模型4：边际效益递减（Diminishing Returns）
> 第一个主题让用户开心，第15个主题只有维护成本。

Themes(15+)就是典型。3个精选主题 vs 15个主题：用户体验差距微乎其微，维护成本翻5倍。

### 模型5：奥卡姆剃刀（Occam's Razor）
> 如无必要，勿增实体。

Walk、CustomFonts、EditHistory、Inbox——每一个都是"万一有人需要呢"的产物。芒格说：**你不需要为假想用户开发功能**。

### 模型6：规模效应（Economies of Scale）
> 社区需要"冷启动"——没有内容就没有人，没有人就没有内容。

日记产品的社交功能天然缺乏网络效应。一个用户写日记不需要朋友也在用。**强行做社交 = 在沼泽地上盖楼。**

### 模型7：避免愚蠢（Via Negativa）
> 最大的进步来自**停止做蠢事**。

## 四、"避免愚蠢"清单：应该砍掉的

**立刻砍掉（投入为正，产出为负）：**

| 功能 | 为什么砍 |
|------|---------|
| **Community** | 需要运营团队、内容审核、冷启动——吞噬资源，产出趋零 |
| **Friends** | 日记不需要好友关系链，强行做 = 产品定位撕裂 |
| **Inbox** | 日记App里聊天 = 做一个没人用的微信 |
| **Leaderboard** | 扭曲用户动机，把内省变成表演 |
| **PostDetail** | 砍社区后自然消亡 |
| **Walk** | 日记App的运动记录 = 不知道自己是谁 |
| **CustomFonts** | 极客玩具，99%用户不关心 |
| **EditHistory** | 日记不是Git，版本管理是伪需求 |

**精简但保留：**

| 功能 | 处理方式 |
|------|---------|
| **Themes(15+)** | 砍到3个精品主题 |
| **AIChat(多风格)** | 保留1种风格，砍掉"多风格"探索 |

**可砍共：8个功能直接砍 + 2个功能精简 = 释放大量开发精力**

## 五、只留10个，留哪些？

> "如果你只能有10个功能，你选哪些？剩下的都不该存在。"

| 优先级 | 功能 | 留下的理由 |
|--------|------|-----------|
| 1 | **Editor** | 产品本身 |
| 2 | **Home** | 每天的第一眼 |
| 3 | **Gallery** | 回看 = 留存的核心 |
| 4 | **Search** | 信任的基石 |
| 5 | **OnThisDay** | 最强情感粘性功能 |
| 6 | **AnnualEcho** | 仪式感，年终引爆分享 |
| 7 | **InsightDraft** | "理解自己"的兑现 |
| 8 | **Login/Register** (合并算1个) | 进门的门槛，越低越好 |
| 9 | **Settings** (含Privacy/Terms) | 必要基建 |
| 10 | **PushNotifications** | 唤回用户最后的武器 |

**砍掉的25个功能**要么是其他10个的子集、要么是不该存在的方向、要么是锦上添花但不产生留存的。
