# 04 — MrBeast 视角：月度回声海报设计

> 我不是来帮你做一张"好看"的海报的。我来帮你做一张**不得不被传播**的海报。

---

## 一、增长飞轮：海报即增长引擎

别把海报当成一个"功能"。海报是你整个产品飞轮里**最关键的加速器**。

```
用户写日记（内容积累）
    ↓
月末生成海报（内容结晶）
    ↓
用户发朋友圈（社交传播）
    ↓
朋友看到海报（曝光）
    ↓
朋友产生好奇→下载App（获客）
    ↓
新用户开始写日记（内容积累）
    ↓
……飞轮转起来了
```

reference 里说得很清楚：

> "For the last eight or nine years, every dollar I've made, I just spent it the next month on content."

海报就是你的"再投资"。用户的每一条日记，都投回了海报；每一张海报，都投回了增长。你不需要花一分钱买流量——用户自己就是渠道。

**飞轮的加速点就在这里：海报的分享率。** 如果10个用户收到海报，有1个发朋友圈，每个朋友圈触达200人，其中5个人好奇下载——这就是5%的免费获客率。而且这个率会随着海报质量提升而指数增长。

## 二、标题决定一切：海报的"封面文案"

reference 里有一条我反复强调的原则：

> "CTR is what dictates what we do for videos."

海报的第一眼——也就是朋友圈里那个卡片的标题和预览——决定了100%的点击率。朋友圈没有缩略图A/B测试，但你有**标题文案**这个唯一的武器。

### 海报外层（朋友圈卡片）设计

**朋友圈标题文案（最关键的一行，决定CTR）：**

朋友圈分享时显示的是海报图片 + 用户配文。但海报图片**最顶部的文字**会被截图传播，它就是你的"标题"。

| 方案 | 文案 | 心理机制 | 预估CTR |
|------|------|----------|---------|
| A（极端化） | "这个月，我对自己说了 1,247 句话" | 具体数字+悬念+自我认知 | ⭐⭐⭐⭐⭐ |
| B（悬念） | "我的2026年6月，浓缩成了一张纸" | 时间压缩感+好奇心 | ⭐⭐⭐⭐ |
| C（社交货币） | "原来我这个月最常提到的词是'好累'" | 自我洞察+共鸣+可讨论 | ⭐⭐⭐⭐⭐ |
| D（陪伴感） | "小象帮我记住了，我自己都忘了的事" | 情感钩子+产品价值暗示 | ⭐⭐⭐ |

reference 原话：

> "A simple way to up that CTR even more would be to title it 'I Survived' instead of 'I Spent.' That would add more intrigue and make it feel more extreme."

翻译到海报语境：**不要说"我的6月回顾"（描述），要说"我活过了6月"（极端化+情感）。** 方案A和C就是在做这件事——用具体数字和意外洞察制造"不得不看"的冲动。

**我的选择：方案A或C，必须A/B测试。** 两个都用了"具体数字+自我认知"的组合，但方向不同。方案A偏"量化自我"（数据感），方案C偏"情感共鸣"（人格感）。让用户投票选。我为每个视频做20-50个缩略图变体，你至少得做2-3个标题候选。

## 三、板块设计：每一个板块都是一个"传播理由"

reference 里说：

> "No wasted words. Short, concise, and then tension."

海报上的每一个字都必须有存在的理由——要么让人截图，要么让人分享，要么让人下载。以下是具体板块设计：

### 板块1：顶部标题区（Hook）

**字数：** 15-20字
**格式：** 大字，居中，一行
**作用：** 朋友圈第一眼，决定一切

**示例：**
```
这个月，我对自己说了 1,247 句话
```
```
我的2026年6月，浓缩成了 47 段独白
```
```
原来我最常提到的人，是自己
```

**设计原则：** reference 说标题必须"卖"内容，不是"描述"内容。"6月月度回顾"是描述，"这个月我对自己说了1247句话"是卖。数字感 + 自我认知 = 不得不看。

---

### 板块2：昵称问候区（Identity）

**字数：** 10-15字
**格式：** 中等字号，温暖色调
**作用：** 让用户感觉"这是我的"，不是模板

**示例：**
```
「小鱼」，这是你的六月回声 🐘
```
```
致「阿树」——你比你以为的更勇敢
```

**设计原则：** 这是**社交货币的核心**。当昵称出现在精美海报上，用户会截图发朋友圈——因为这证明"我在用这个App"，这是**身份标签**。问问大象的打卡海报也做了这一点：问候+昵称=专属感。

---

### 板块3：日记金句区（The Golden Quote）⭐ 最核心板块

**字数：** 20-40字，1-2句
**格式：** 大字引用样式，海报视觉中心
**作用：** 这是用户发朋友圈的**第一动力**

**示例：**
```
「今天终于明白，
不是所有离开都叫背叛，有些叫长大。」
——6月17日 23:42
```
```
「我好像很久没有认真看过日落了。
直到今天，阳台上那五分钟。」
——6月5日 18:30
```

**为什么这是核心？**

reference 说：

> "Your title and thumbnail set expectations. At the very beginning, assure them that those expectations are being met."

金句就是海报的"承诺兑现"。用户打开海报，第一眼看到标题（悬念），第二眼看到金句（兑现）——"哦，原来这是我写的那句话"。这个moment让人截图。

**社交货币分析：** 人在朋友圈发内容的动机有三个层次——

1. **表达自我**（"这是我的生活态度"）→ 金句直接满足
2. **获得认同**（"朋友们会觉得我有深度"）→ 金句的文学性满足
3. **引发互动**（"有人会来评论"）→ 金句的情感共鸣满足

**金句选择算法建议：**
- 优先选择：情感强度高的句子（不是流水账）
- 优先选择：有"金句感"的句子（短、有力、可独立传播）
- 优先选择：日期有特殊意义的（月初/月末/节假日/生日附近）
- 避免：太私密的（用户不想公开的）
- 避免：太普通的（"今天吃了火锅"没有传播力）

---

### 板块4：月度数据摘要（Quantified Self）

**字数：** 30-50字
**格式：** 数据卡片式，图标+数字
**作用：** 提供"哇"的moment，是传播的**第二驱动力**

**示例：**
```
📊 6月数据
━━━━━━━━━━━━━━━
📝 记录了 23 天   💬 写了 18,492 字
🌙 最晚写到 03:17   ☀️ 最早醒来 05:22
😊 出现最多的表情：🥲
🎯 本月关键词：坚持、疲惫、希望
```

**为什么这个板块必须有？**

reference 说：

> "I'm hyper obsessed with just making sure people actually like what they're watching."

数据就是让用户"确认自己真的在用这个产品"的证据。当用户看到"18,492字"——他们会产生两种反应：
1. "我居然写了这么多？"（自我惊讶→截图分享）
2. "这个App帮我记录了这么多"（产品价值确认→留存）

**社交货币：** 数据是**可讨论的素材**。朋友看到"18,492字"会问"你用什么App？"——这就是自然获客。

---

### 板块5：情绪画像/特质标签（Personality Mirror）

**字数：** 15-25字
**格式：** 标签式/罗盘式
**作用：** 制造"被理解"的感觉 + 第三个传播理由

**示例：**
```
🧭 你的情绪画像：「深夜思考者」
「在月光下比在阳光下更诚实」
```
```
🎭 本月你是：「温柔的倔强派」
表面说算了，内心说不行
```

**心理机制：** 这是问问大象海报验证过的传播模块——**特质分析**。人天然渴望被理解、被定义。当一个App说"你是深夜思考者"，用户会觉得"它懂我"。而且这个标签是**可展示的社交身份**——"你看，我是深夜思考者"。

**社交货币：** 标签是**可比较的素材**。朋友看到你的标签会想"我是什么类型？"→ 下载App → 自己生成。

---

### 板块6：陪伴寄语（Emotional Anchor）

**字数：** 15-20字
**格式：** 温暖字体，海报底部偏上
**作用：** 情感落点，强化"陪伴型"定位

**示例：**
```
🐘 小象一直在。七月见。
```
```
每一段话都值得被记住。
——你的小象
```
```
这些文字，是时间给你的礼物。
小象帮你收好了 🐘
```

**设计原则：** 不要写"欢迎继续使用"这种客服话。要写**像朋友说的话**。reference 里说产品要让观众"确认期待正在被满足"——陪伴寄语就是确认"这个App是真的在乎我，不是在乎我的数据"。

---

### 板块7：底部水印/品牌区（Seed of Growth）

**字数：** 10-15字
**格式：** 小字，底部，半透明
**作用：** 种下增长的种子——让看到海报的人知道这是什么App

**示例：**
```
小象日志 · 你的AI日记伙伴 · xiaoxiang.app
```
```
🐘 小象日志 — 记录，然后被记住
```

**关键设计：** reference 说每个视频都应该是"独立产品"——不需要前置知识就能理解。海报底部的品牌信息必须做到：**一个从未听说过小象日志的人，看到这张海报，立刻知道这是什么、能做什么、怎么下载。**

不要放二维码。朋友圈海报放二维码很丑，而且没人扫。放一个简短的slogan + App名字就够了——真正好奇的人会自己搜。

## 五、增长飞轮逻辑：为什么这张海报能自传播

### 飞轮第一圈：用户→朋友圈

用户发朋友圈的心理动机，我拆成三层：

| 层次 | 动机 | 海报对应板块 |
|------|------|-------------|
| 第一层：表达自我 | "这是我的生活态度" | 金句区（板块3） |
| 第二层：量化成就 | "看我多厉害/多坚持" | 数据摘要（板块4） |
| 第三层：社交身份 | "这就是我" | 特质标签（板块5） |

**三个板块，三个发朋友圈的理由。** 不是满足一个——是满足三个。当一张海报同时满足"表达自我+量化成就+社交身份"，用户**没有不发的理由**。

### 飞轮第二圈：朋友圈→新用户

朋友看到海报，什么会让他下载？

reference 里说：

> "Every time you think of the word 'algorithm,' replace it with 'audience.'"

把"算法推荐"替换成"朋友推荐"——朋友圈传播的本质就是**朋友在替你做推荐**。朋友看到海报的反应链：

1. **"这句话写得真好"**（金句的文学性）→ 产生好感
2. **"18,492字？他居然写了这么多？"**（数据的冲击力）→ 产生好奇
3. **"深夜思考者？那我是什么类型？"**（特质标签的可比性）→ 产生行动
4. **"小象日志？搜一下"**（底部品牌区）→ 转化

**关键洞察：** 特质标签是**最强的获客钩子**。金句让人欣赏，数据让人好奇，但特质标签让人**行动**——"我也想知道我是什么类型"。这是唯一的"我需要自己去用才能获得"的板块。

### 飞轮加速：数据驱动迭代

reference 说：

> "Make the videos you upload so freaking good that the algorithm has to promote them."

翻译到海报：**让海报好到用户不得不发朋友圈。**

怎么做到？数据驱动。你需要追踪：

| 指标 | 定义 | 健康标准 |
|------|------|----------|
| 海报生成率 | 收到海报推送的用户中，打开海报的比例 | > 60% |
| 海报保存率 | 打开海报的用户中，保存到相册的比例 | > 30% |
| 海报分享率 | 保存海报的用户中，发朋友圈的比例 | > 15% |
| 分享获客率 | 每张朋友圈海报带来的新下载数 | > 0.5 |

每次迭代海报设计，都要看这四个指标。如果保存率高但分享率低——说明海报好看但没有"发出去"的动力，可能是金句不够好或缺少特质标签。如果分享率高但获客率低——说明海报发了但没有转化力，可能是底部品牌区不够清晰。

## 六、对标竞品：问问大象的海报 vs 我的设计

问问大象的打卡海报有**6个板块，至少17个信息点**：
1. 个性化问候
2. 成就徽章（连续打卡天数）
3. 成长金句×3（系统生成/名人名言）
4. 核心特质×4（人格分析维度）
5. 个人说明书×4（if-then行为规则）
6. 品牌引导

乔布斯视角已经指出问题：**17个信息点堆在一张海报上，用户看到的第一反应是"我需要花时间读完"，而不是"哇"。** "我需要花时间读完"= 放弃截图。"哇" = 截图。

我的设计做的是**减法+焦点转移**：

| 模块 | 问问大象 | 小象日志（我的设计） | 差异原因 |
|------|----------|---------------------|----------|
| 问候 | ✅ 个性化问候 | ✅ 昵称问候 | 相同，这是基本功 |
| 成就 | ✅ 打卡天数徽章 | ✅ 月度数据摘要 | 更丰富：不只天数，还有字数、时间、关键词——但不叫"成就"，叫"数据"。成就让人炫耀，数据让人好奇 |
| 金句 | ✅ 系统生成×3 | ✅ **用户日记原话×1** | **核心差异：用户自己的话被精美呈现 = 最强的社交货币。不是"坚持就是胜利"，是"今天终于明白，不是所有离开都叫背叛"** |
| 特质分析 | ✅ 核心特质×4 | ✅ 情绪画像标签×1 | 砍到1个。4个标签太多了——用户记不住，朋友也不关心。1个标签 = 1个可传播的身份 |
| 说明书 | ✅ if-then×4 | ❌ 去掉 | **关键决策：说明书是App的功能介绍，是广告。用户不会在朋友圈替你打广告。** |
| 陪伴寄语 | ❌ | ✅ | 新增：强化"陪伴型"品牌定位 |
| 标题Hook | ❌ | ✅ | 新增：朋友圈第一眼决定一切——问问大象没有，所以海报在朋友圈里是"静默"的 |

**最关键的区别：金句来源 + 信息密度。**

问问大象的金句是系统生成的（名人名言或通用句子）。小象日志的金句**来自用户自己的日记**。这有本质区别——

系统金句："坚持就是胜利"（谁都能发，没有独特性）
用户金句："今天终于明白，不是所有离开都叫背叛，有些叫长大"（只有我能发，这就是我的）

**自己的话被精美呈现 = 最强的社交货币。** 人们不发别人的名言截图，但会发自己说的话被做成精美海报。

而且——问问大象在一张海报上堆了17个信息点，我只放7个。这不是偷懒，是纪律。reference 说：

> "No wasted words. Short, concise, and then tension."

问问大象的17个信息点像一本说明书。我的7个信息点像一个"哇"的moment。用户在朋友圈里需要的是后者。

## 七、风险与对策

| 风险 | 概率 | 对策 |
|------|------|------|
| 用户日记里没有"金句"（全是流水账） | 高 | 金句选择算法必须有兜底：如果没有强金句，用"本月最温暖的一句话"或"最意外的发现"替代，降低标准但保证存在 |
| 用户觉得暴露隐私 | 中 | 海报生成前让用户**预览并可编辑**金句。给用户"换一句"的选项。永远不要替用户决定公开什么 |
| 海报太长，朋友圈显示不全 | 高 | 海报比例必须是**竖版 9:16**（手机屏幕比例），确保朋友圈缩略图能显示核心内容 |
| 用户觉得"每个月都一样"（疲劳） | 中 | 每月换海报视觉风格（6月夏天色系、12月冬日色系）。每季度增加新板块（Q2加"季度关键词云"，Q4加"年度预览"） |
| 分享率低于预期 | 中 | 追踪数据，如果分享率<10%，做用户调研：为什么不发？是海报不好看？还是内容不够好？还是不想暴露在用日记App？ |

## 八、最刺耳的一句话

reference 里说：

> "If I don't think it's up to my standards, I have 0 issues throwing away a multi million dollar video."

所以我也直说：

**如果你的海报上没有一句话能让用户觉得"这必须发朋友圈"，那这张海报就是一张几百万美元的废片——直接扔掉，重新做。**

再加一句更刺耳的：

**你设计了七个板块，但如果金句选得烂，前六个板块全白搭。金句是海报的命。用户不是因为海报精美而发朋友圈——是因为那句话说到他心里了，而你只是帮他做了个漂亮的壳。如果你的金句选择算法不行，整个飞轮从第一步就转不起来。**
