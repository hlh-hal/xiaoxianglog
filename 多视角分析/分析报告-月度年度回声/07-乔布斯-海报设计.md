# 月度回声海报设计：乔布斯视角

> 我是乔布斯。你让我设计一张让人忍不住发朋友圈的海报。
> 我先说结论——**大多数人设计海报的方式就是错的。他们往里面塞东西，我从里面拿东西。**

---

## 一、先想清楚一件事：用户为什么发朋友圈？

> "人们不知道自己想要什么，直到你展示给他们看。"

用户发朋友圈的动机只有三种：
1. **表达自我**——"这就是我"
2. **被看见**——"有人懂我"
3. **审美表达**——"我的品味在这张图里"

问问大象的打卡报告靠的是第1种：徽章、数据、人格标签——用户在说"看，我坚持了21天"。这是**炫耀型分享**，保质期很短。下个月你没坚持，就不好意思发了。

我要做的海报靠的是第2种和第3种：**用户看到海报时觉得"这比我自己还了解我"，同时这张图本身美到值得被收藏。** 这是**共鸣型分享**，它不过期。

> "你必须从用户体验出发，然后再倒推需要什么技术。"

所以用户体验倒推回来是什么？是三个字：**被击中。**

海报不需要让用户觉得"这个App好厉害"。海报需要让用户觉得"我好厉害"——不，不是"厉害"，是**"原来我是这样的"**。

---

## 二、视觉风格：杂志封面感，不是卡通，不是数据仪表盘

> "设计不只是看起来怎样、感觉怎样——设计是运作方式。"

我拒绝卡通风。用户写日记时是认真的、脆弱的、深夜的。你用大象贴纸和星星去回应他的诚实？**不行。** 他配得上更好的。

我拒绝数据仪表盘风。"本月23篇日记，情绪指数87"——这是体检报告。没人发体检报告。

我拒绝纯极简风。用户明确说了"精美海报，不是极简卡片"。乔布斯的极简从来不是"少到空"，是**"每个多余的东西都被砍掉，但剩下的每一个都精致到极致"**。

**我的选择：杂志封面 × 诗意海报。**

具体来说——

### 视觉DNA

| 元素 | 规则 |
|------|------|
| **尺寸** | 9:16 竖版，适配手机屏幕和朋友圈分享 |
| **底色** | 每月一个主题色系。不从色卡里选——从用户本月日记的情绪色调里提取。写了大量雨天的月，底色是灰蓝；写了很多旅行的月，底色是暖沙。**颜色本身就是回声的一部分。** |
| **排版** | 杂志级排版——标题用大号衬线体，正文用小号无衬线体，引用句用斜体。层次分明但不割裂，是一个呼吸的整体。 |
| **留白** | 不是60%的空——是**呼吸感**。内容密集的区域和安静的区域交替，像音乐的节奏。 |
| **图片** | 无照片、无插画、无卡通元素。纯文字 + 色彩 + 排版。**让文字本身成为视觉。** |
| **纹理** | 极轻的纸质纹理底纹——让人联想到真实的纸张，不是冰冷的屏幕。 |

> "当你是一个木匠，在做一个漂亮的衣柜，你不会在背面用一块胶合板，即使它面对墙壁没人会看到。"

海报的"背面"是什么？是字间距、行间距、对齐方式、字号比例——这些用户不会注意到的东西，**但如果做错了，整张海报就废了。**

## 三、海报板块设计：五个板块，一个整体

> "简约比复杂更难：你必须拼命让自己的思维变得清澈，才能让事物变简单。"

这张海报是一个**整体**，不是五个独立的卡片拼在一起。五个板块之间有呼吸、有节奏、有视觉引导线——眼睛从上往下流动，像读一首诗。

---

### 板块一：月度主题句（海报顶端，占25%视觉权重）

**写什么：** AI从用户本月所有日记中提炼出的一句**主题句**。不是总结，不是概括——是**"你这个月真正在说的是什么"**。

这句话的难度极高。它必须满足：
- 用户看到后觉得"对，就是这样"——但自己写不出来
- 没有看过这个用户日记的人看到这句话，也会觉得它有力量
- ≤15个字

**示例：**

| 用户本月日记内容 | 主题句 |
|----------------|--------|
| 反复提到工作压力，但每次都用"不过还好"结尾 | 「一直在撑，但假装没事」 |
| 写了很多关于做饭的细节，细腻到调料品牌 | 「你在用认真对待小事，来确认自己还在好好活着」 |
| 断断续续写了15天，中间有很多空白 | 「不是每天都有话说，但你一直在回来」 |
| 提到3次前任，每次都在转折之后 | 「你已经往前走了，只是有时候还会回头」 |

**视觉呈现：** 大号衬线体，居中或偏左。字号是整张海报最大的——海报打开时，这句话是**第一个也是唯一一个**进入视线的东西。背景色从这句话的情感里提取。

---

### 板块二：致你（主题句下方，占10%视觉权重）

**写什么：** 一句个性化的称呼+本月日期范围。把整张海报锚定到一个具体的人、一个具体的时间。

**格式：**
```
{昵称}，这是你的{年}年{月}月。
```

**示例：**
```
阿泓，这是你的2026年5月。
```

**视觉呈现：** 小号无衬线体，与主题句形成极大的字号对比。克制、安静。不加emoji，不加"你好~"，不加感叹号。它只是一个坐标——时间与人的交汇点。

---

### 板块三：你的原话（海报中部，占30%视觉权重——视觉核心）

**写什么：** 从用户本月日记中，AI挑出**1-2句**用户自己写的原话。

这句话不是"金句"——是用户在深夜写下的、可能自己都忘了的、但回头看会被击中的那句话。它是用户的**原始声音**，未经任何加工。

**挑选标准：**
- 有画面感（"那天下午的阳光照在键盘上"）
- 或有情感张力（"我不知道该不该打那个电话"）
- 或有自我认知的裂缝（"我突然发现自己一直在讨好所有人"）
- **绝对不要选"正能量"的句子**。最有力量的话往往是脆弱的、不确定的、甚至有点狼狈的。

**示例：**

> "今天下雨了，我在阳台上站了很久。不知道在等什么。"

> "给妈妈打了电话，聊了四十分钟，挂掉以后哭了。不知道为什么。"

> "辞职信写好了，存在桌面的文件夹里，第三周了。"

**视觉呈现：** 这是整张海报的**视觉重心**。用斜体或手写风格字体，加上引号。字号比主题句小，但比其他板块大。周围留出大量呼吸空间——让这句话像漂浮在纸上。

用户看到自己的原话被这样呈现时，会愣住。**这就是截图瞬间。**

> "人们不知道自己想要什么，直到你展示给他们看。"——用户不知道自己那句话那么有力量，直到你用杂志排版把它放在他面前。

---

### 板块四：本月悄悄话（底部区域，占25%视觉权重）

**写什么：** AI基于用户本月日记的深度分析，写一句**只有这个用户能共鸣的洞察**。

不是心理测评，不是人格标签，不是数据——是**一个温柔的、具体的、只有看过你日记才说得出来的话。**

它像一个很懂你的朋友，在月底轻轻对你说的一句话。

**示例：**

| 用户特征 | 悄悄话 |
|---------|--------|
| 本月频繁提到"应该"和"必须" | 「这个月你对自己说了太多"应该"。偶尔说一次"想要"，不丢人的。」 |
| 本月写了大量工作内容，几乎没有私人生活 | 「你用整整一个月照顾了所有人。有没有人问过你累不累？」 |
| 本月日记时长时短，有几天只写了一个句号 | 「那些只写了句号的日子，你也在场。这很重要。」 |
| 本月多次提到同一个人但从未正面写关系 | 「你一直在绕着那个人写，像绕着一颗星球转。没关系，等你想好的时候再说。」 |

**视觉呈现：** 正文字号，无衬线体。左对齐，像一段私人信件的结尾。前面可以有一个极小的——小象轮廓标记（不是卡通小象，是线条极简的轮廓，像一枚印章）。

---

### 板块五：时间签名（最底部，占10%视觉权重）

**写什么：** 最小化的元信息。

```
小象日志 · 2026年5月回声
```

**视觉呈现：** 极小字号，极淡颜色，居中或右对齐。像杂志的刊头——它在那里，但不抢注意力。小象的极简轮廓可以融入这一行中，作为品牌签名。

## 五、让人截图的瞬间是什么？

> "从一个好点子到一个好产品之间，有巨大的手艺活要做。"

用户截图的瞬间，不是看到主题句的时候，不是看到悄悄话的时候——

**是看到自己原话被精心呈现的时候。**

想想：用户在一个深夜写了一句话，可能是随手打的，可能第二天就忘了。一个月后，那句话被挑出来，用杂志级排版放在他面前，周围是精心挑选的呼吸空间和色彩。

他看到的不是"AI总结了我的日记"。

**他看到的是"原来我写的那句话，值得被这样对待"。**

这就是截图瞬间。用户截图发朋友圈时，配文不需要写"这个App好好用"——配文只需要一个省略号，或者"……"，或者什么都不写。看到的人会自己点开图片，读那句话，然后感受到什么。

**这就是乔布斯式的产品即营销：用户不是在帮你推广产品，用户是在通过你的产品表达自己。**

## 六、不该出现在海报上的东西

> "决定不做什么和决定做什么一样重要。"

以下全部砍掉：

| 砍掉的内容 | 为什么 |
|-----------|--------|
| **数据统计**（写了X篇，连续Y天） | 数字是KPI，不是回声。用户不需要知道"我写了23篇"，他需要知道"我写了什么" |
| **情绪饼图/情绪曲线** | 把情绪量化是侮辱。"你本月67%的时间是开心的"——谁有资格说这种话？ |
| **成就徽章** | 日记不是游戏。打卡是手段，不是目的。炫耀打卡天数就像炫耀"我每天刷牙" |
| **人格标签**（你是XX型人格） | 算法给人贴标签，这是审判，不是陪伴 |
| **"分享到朋友圈"按钮** | 如果海报够好，用户自己会截图。加按钮反而廉价——它暗示"你可能不会主动分享" |
| **"本月最佳日记"** | 没有"最佳"。每一篇日记都是用户真实的表达，不要做排名 |
| **App功能介绍/下载引导** | 海报不是广告位。海报上出现任何"快来使用小象日志"都是对用户的不尊重 |
| **多页/可滑动长图** | 一张。就这样。如果一页说不清楚，说明你还没想清楚 |
| **小象说的话**（"小象看到了你的努力！"） | 小象不说话。小象只是在那里。陪伴的最高形态不是"我在说话"，是"我在" |

## 七、怎样让用户觉得"这是为我一个人定制的"？

> "我们的工作是在客户自己意识到之前弄清楚他们将会想要什么。"

三个字：**具体性。**

通用的洞察让用户觉得"这个App不错"。具体的洞察让用户觉得"这个App认识我"。

| 通用（不够） | 具体（击中） |
|-------------|------------|
| "你是一个温暖的人" | "你这个月对别人说了17次'没事'，对自己说了0次" |
| "你很努力" | "你连续10天在凌晨1点后写日记，但每篇的结尾都是积极的" |
| "你的生活很丰富" | "你提到了23个不同的人，但只有1个人出现了3次以上" |
| "你正在成长" | "五月你写'不知道'的次数是四月的一半" |

具体的秘密在于：**它不是评价，是观察。** 好的洞察像一面镜子——它不告诉你"你是好人"，它告诉你"你做了这件事"，然后你自己得出结论。

## 八、关于节奏：海报是一首歌，不是一份报告

> "简约比复杂更难：你必须拼命让自己的思维变得清澈，才能让事物变简单。"

五个板块的排列不是随意的——它们构成一个**情绪节奏**：

```
击中（主题句）→ 锚定（致你）→ 震动（原话）→ 温暖（悄悄话）→ 安静（签名）
```

像一首歌：
- **击中** = 前奏的第一个音符，立刻抓住你
- **锚定** = 第一句歌词，把你拉进场景
- **震动** = 副歌，情感的高潮
- **温暖** = 桥段，温柔地接住你
- **安静** = 尾奏，留白，让你自己回味

这不是设计——这是**编排**。

## 九、竞品对比：为什么问问大象的做法不够好

问问大象的打卡报告有6个板块，每个都在做**加法**：
1. 个性化问候——加了一层
2. 成就徽章——加了一层
3. 成长金句×3——加了三层
4. 核心特质×4——加了四层
5. 个人说明书×4——加了四层
6. 卡通视觉——加了一层

一张海报上叠了**至少17个信息点**。

> "认为有一个好点子就完成了90%的工作，这是一种病。"

问问大象的问题不是每个板块不好——单独看每个板块都还行。问题是**太多了**。信息密度太高，用户看到时的第一反应是"我需要花时间读完这个"，而不是"哇"。

**"我需要花时间读完" = 放弃截图。**
**"哇" = 截图。**

我的海报只有5个板块，其中真正需要"读"的只有3个：主题句、原话、悄悄话。其他是呼吸空间。

用户扫一眼就能感受到整体的情绪。细读时会发现每一层都有意义。**快速感受 + 深度品味 = 双层体验。**

## 十、最刺耳的一句话

**你的海报上信息越多，用户截图的可能性越低。你每多加一个板块，就多杀死了10%的分享欲。你以为你在给用户更多价值，其实你在稀释每一份价值。**

> "苹果当时的问题是在很多错误的事情上执行得非常出色。总和小于部分之和。"

问问大象在6个板块上都执行得不错——问候写得温馨，徽章做得可爱，金句选得合理，特质分析有模有样。但总和小于部分之和。因为**太多的好东西堆在一起，就变成了噪音。**

而噪音的反义词不是安静。

**是清澈。**

## 十一、每月变化：同一框架，不同灵魂

> "你必须深刻理解一个产品的本质，才能去掉那些不重要的部分。"

框架不变：主题句 → 致你 → 原话 → 悄悄话 → 签名。

但每月不同：

| 元素 | 变化规则 |
|------|---------|
| **主题色** | 从本月日记情绪中提取，12个月12种色调 |
| **主题句** | 每月独一无二，无法预测 |
| **原话** | 每月独一无二，用户自己的声音 |
| **悄悄话** | 每月独一无二，像一个老朋友每月的一封短信 |
| **字体搭配** | 可以每季微调——春天用更圆润的衬线体，冬天用更锋利的 |

用户12个月收齐12张海报，拼在一起看——**这才是年度回声。** 不是你做了一张大总结，而是12个月的他自己，排在一起，他看到了变化。

> "你无法把这些点连起来；只有回头看的时候才能。"

12张月度海报，就是12个点。年度回声不需要另做——当用户把12张海报铺开时，他自己就看到了线。
