# 小象回声浮窗设计 - 多视角汇总报告

> 分析日期：2026-06-02
> 视角：产品克制 / 情感体验 / 用户控制
> 核心问题：小象回声改成一只活泼可爱的浮窗小象，怎样有情感记忆点，又不打扰写日记？

## 一句话结论

小象回声可以做成“活泼可爱的小象”，但不应该做成常驻浮窗宠物。最适合小象日志的方案是：保存日记后，小象从纸页右下角短暂探出，用一句很短的回声回应用户；用户主动点击后才展开完整回声卡，几秒后自动退回纸角。

它不是 AI 助手入口，也不是桌面宠物，而是写完日记后的温柔回音。

## 多视角共识

1. 不做常驻浮窗

常驻小象会从“陪伴”变成“存在感”，和日记应用需要的安静、私密、留白冲突。用户写日记时主角应该是文字和自己，不是小象。

2. 出现时机比可爱程度更重要

小象最该出现的时刻只有一个：用户保存日记成功后。这个时刻用户完成表达，情绪从书写转向收束，小象出现才像“我听见了”，而不是打断。

3. 小象要绑定在这篇日记上，不要绑定在整个 App 上

小象回声属于某一篇日记的回声，不是全局 AI 入口。它应该从回声卡、保存成功区域、纸页边角出现，而不是像客服按钮一样固定在全局右下角。

4. 用户必须有控制权

必须支持“本次关闭 / 今天安静 / 关闭小象浮窗 / 切回普通回声卡”。日记是私密场景，用户不想被陪伴时，产品要体面退后。

## 推荐方案：纸角探头小象

### UI 位置

移动端：

- 默认位置：编辑器内容区右下角，靠近纸页边缘。
- 离底部安全区、输入框、图片按钮、工具栏至少 16-24px。
- 键盘弹起时隐藏，不悬浮到键盘上方。
- 用户滚动正文或继续输入时自动收起。

桌面端 / 宽屏：

- 位置在日记正文容器右下侧，不贴浏览器窗口最右侧。
- 不超过正文阅读宽度边界，避免客服插件感。

### 视觉形式

小象不是高饱和 IP 角色，而是“纸页上活过来的小插画”：

- 手绘线条、水彩纸感、低饱和。
- 身体用暖灰、灰绿、米白。
- 主色 `#446733` 只用于耳朵边缘、鼻尖、小叶子、描边或小线条。
- 默认尺寸 48-56px，展开后卡片宽度不超过屏幕 86%-92%。
- 不用 3D、强阴影、闪光、彩带、红点、跳动提醒。

### 出现方式

保存成功后：

1. 300-600ms 后，小象从纸页右下角轻轻探头。
2. 鼻尖画出一条很细的绿色弧线。
3. 弧线后面展开一张小纸条，只显示一句短回声。
4. 停留 3 秒左右。
5. 自动收回到纸角，只留下一个很轻的小象入口。

动画原则：

- 主动画 600-900ms 内完成。
- 停留不超过 4 秒。
- 默认无声。
- 可选极轻 haptic，但不做动物叫声。
- 支持系统“减少动态效果”。

## 交互状态

### 1. 写作中

小象默认不可见，或只露出极弱的纸角痕迹。

规则：

- 正在输入时不冒泡。
- 键盘打开时隐藏。
- 选中文字、插入图片、操作工具栏时不出现。
- 滚动正文时降低存在感或收起。

### 2. 保存中

不做夸张 loading。可以让小象在纸角抱着一片小叶子，表示“正在收好”。

保存失败时不要卖萌，直接给清楚恢复动作：

> 还没有收好，点这里再试一次。

### 3. 保存成功

小象探出，显示短回声纸条：

> 小象听见了。

或：

> 这段心事，已经被好好收下了。

### 4. 用户点击小象

展开完整“小象回声”轻卡片。

卡片内容仍然克制，不改成长篇聊天：

- 一段温柔回应，建议 80-180 字。
- 按钮：`收进这篇` / `换一句` / `保存回声图` / `不再显示`
- 二级入口可放 `继续聊聊`，但不要作为主按钮。

### 5. 自动收起

用户无操作 3-4 秒后，小象收回纸角。完整回声不自动展开。

## 内容策略

浮窗状态只显示一句极短文本，完整分析留给展开后的回声卡。

好文案：

- 小象听见了。
- 这段心事，已经被好好收下了。
- 有些感受不用马上解决，先被看见就好。
- 你今天写得很认真。
- 这不是小事，它是你今天的一部分。

避免文案：

- 恭喜完成今日打卡！
- 你的焦虑指数较高，请立刻调节。
- 太棒啦，继续保持！
- 点击查看 AI 深度分析！
- 小象有新发现！

## 保存与回看闭环

### 收进这篇

保存到 `DiaryEntry.dailyEcho`，作为日记附属内容，不插入正文，不污染用户原文。

回看日记时：

- 日记底部显示“小象回声 · 1 条”。
- 点击后展开当时保存的回声。
- 小象可以轻轻露出一次，但不重复播放完整动画。

### 保存回声图

生成一张纸感回声图片：

- 顶部：小象回声 + 日期
- 中间：回声内容
- 底部：小象日志轻标识
- 默认不包含原日记正文
- 用户主动选择才保存到图库

### 不再显示

提供三层控制：

- 本次关闭
- 今天安静
- 关闭小象浮窗

设置页提供：

- 小象回声：开 / 关
- 显示方式：纸角小象 / 底部回声卡 / 仅保存提示
- 自动生成：保存后生成 / 点击后生成
- 保存到图册：每次询问 / 从不

## MVP 版本

第一版只做 5 件事：

1. 保存成功后右下纸角小象探头。
2. 展示一句短回声纸条。
3. 3 秒后自动收起。
4. 点击展开现有小象回声卡。
5. 提供“不再显示 / 设置关闭”。

第一版不要做：

- 全局常驻浮窗
- 换装、等级、成长系统
- 随机互动
- 语音播报
- 主动提醒写日记
- 大面积动画
- 默认展开长文 AI 分析

## 推荐优先级

1. 先做“保存成功后的纸角探头小象”
2. 再做“点击展开回声卡”
3. 再做“保存回声图和回看入口”
4. 最后再考虑更多表情和动效

## 最刺耳但必要的话

如果这只小象需要一直悬在屏幕上，用户才记得它，那说明真正不够动人的不是浮窗，而是“小象回声”本身。

小象日志不缺一个会卖萌的角色，它缺的是一个懂得什么时候闭嘴、什么时候轻轻回应的灵魂。
