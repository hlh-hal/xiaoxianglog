# 从飞轮视角设计"深一层追问"

> 视角：Jeff Bezos / 亚马逊飞轮理论
> 核心命题：深一层追问如何形成"越追问越懂你"的增长飞轮？

---

## 一、先画飞轮：深一层追问的闭环

我做亚马逊时，飞轮的核心逻辑是：**每一环的输出，自动成为下一环的输入。** 让我画出小象日志的飞轮——

```
用户写日记（情感内容输入）
       │
       ▼
┌─────────────────┐
│  AI生成温暖回声   │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  用户点"深一层"   │ ◄──────────────────────────┐
└────────┬────────┘                               │
         │                                        │
         ▼                                        │
┌─────────────────┐                               │
│ AI基于上下文追问  │                               │
└────────┬────────┘                               │
         │                                        │
         ▼                                        │
┌─────────────────┐                               │
│  用户回答/反思    │                               │
└────────┬────────┘                               │
         │                                        │
         ▼                                        │
┌─────────────────┐                               │
│ 系统积累用户画像  │  ← 情感模式、关注主题、表达习惯  │
└────────┬────────┘                               │
         │                                        │
         ▼                                        │
┌─────────────────┐                               │
│ 下次回声更精准    │  ← 画像反哺生成质量              │
└────────┬────────┘                               │
         │                                        │
         ▼                                        │
     用户体验提升 ──→ 信任加深 ──→ 更愿意深一层 ─────┘
```

**关键洞察：这不是一个功能，这是一个飞轮。** 每一次"深一层"都在喂养系统，让下一次回声和追问更精准，用户感知到"它越来越懂我"，就更愿意继续追问。

---

## 二、飞轮的四个加速点

### 加速点 1：降低"深一层"的摩擦

亚马逊的核心信条——减少摩擦就能增加交易量。对小象日志来说：

**现状问题：** 点"深一层"后等待时间长、追问可能跟用户情绪不搭。

**设计原则：**
- "深一层"按钮永远紧贴回声气泡下方，**零搜索成本**
- 追问内容基于**当前这条回声**而非重新生成，响应更快（< 1.5秒）
- 追问不超过一句话，像朋友随口接话，不像心理咨询师提问

**具体实现：**
```
┌──────────────────────────────────┐
│  AI回声：今天和妈妈的对话，你选了   │
│  沉默。沉默有时候是最温柔的保护。   │
│                                  │
│  ┌──────────┐  ┌──────────────┐  │
│  │ 深一层 ↓  │  │  继续聊聊 💬  │  │
│  └──────────┘  └──────────────┘  │
└──────────────────────────────────┘

点击"深一层"后：
┌──────────────────────────────────┐
│  AI追问：那个沉默的瞬间，你心里    │
│  最先冒出来的是什么感觉？          │
│                                  │
│  ┌──────────┐  ┌──────────────┐  │
│  │ 再深一层 ↓ │  │  差不多了 ✓   │  │
│  └──────────┘  └──────────────┘  │
└──────────────────────────────────┘
```

### 加速点 2：追问产生独特的数据资产

亚马逊飞轮中，更多卖家 → 更多选择 → 更好体验 → 更多买家 → 更多卖家。小象日志的等价物：

**更多追问 → 更深表达 → 更丰富的用户情感画像 → 更精准的回声 → 更愿意追问**

每一次追问回答，用户贡献的不是普通文本，而是**深层情感信号**——

| 数据层级 | 来源 | 价值 |
|---------|------|------|
| 表层事实 | 日记正文 | "今天加班了" |
| 情感色彩 | AI回声交互 | 用户是否接受"疲惫"这个标签 |
| 深层模式 | **深一层追问回答** | "我害怕让领导失望" → 核心恐惧 |
| 行为趋势 | 跨天追问积累 | 该用户在"关系"话题追问最深 |

**深一层回答是最稀缺、最高价值的数据。** 它们是用户主动掏出来的内心，别的渠道拿不到。

### 加速点 3：画像反哺——"越懂你"的飞轮加速器

```
第1次追问 → 发现用户在意"被认可"
            ↓
画像更新：情感标签 += [被认可焦虑, 中等强度]
            ↓
第5次追问 → 发现"被认可焦虑"在工作场景触发最频繁
            ↓
画像更新：场景标签 += [工作-领导评价, 高频触发]
            ↓
第10次 → AI回声自动关联：
  "又加班到这么晚。你好像一直在用努力来换取一份确定感，
   像上次你说害怕让领导失望那样。这次，你觉得自己做到了吗？"
            ↓
用户感受："它居然记得上次的事，而且说到了我心坎里"
            ↓
信任飞轮加速 ──→ 更深追问 ──→ 更多数据 ──→ ...
```

### 加速点 4：限制即信任——深度上限的战略意义

**亚马逊学到了一件事：不是所有增长都是好的增长。** Prime 会员费是门槛，但门槛本身创造了信任。

**深一层追问上限：每天3层。** 理由：

1. **稀缺性创造价值。** 无限追问会让用户觉得廉价，3层是"它懂得适可而止"
2. **保护用户。** 情感深挖有风险，3层是安全边界
3. **制造期待。** "今天深挖到第2层就停了"——明天还想来

```
深一层 ──→ 深二层 ──→ 深三层 ──→ 温柔收束
  "那个沉默     "你怕的      "如果下次     "你今天往
   的瞬间，      是失望，      再遇到，      心里看了
   什么感觉？"   还是失去？"   你想怎么做？"  很深呢。"
```

到达第3层后：
- 不显示"再深一层"按钮
- 收束语自动生成，总结今天追问的发现
- 将追问链路整体存入**用户情感档案**

## 三、Prompt 设计——飞轮的引擎

### 基础 Prompt（第1层追问）

```
你是小象日志的AI回声。用户刚写了一段日记，你生成了一条温暖回声。
现在用户点击了"深一层"。

规则：
1. 基于当前回声和日记内容，提出一个开放式追问
2. 追问要像朋友随口接话，不是审问
3. 只问一个问题，不超过25字
4. 语气温暖、好奇、不评判
5. 如果用户日记涉及敏感话题（自伤、极端情绪），不追问，改为温和陪伴

日记：{diary_text}
回声：{echo_text}
用户画像摘要：{user_profile_summary}

生成追问：
```

### 追问深化 Prompt（第2-3层）

```
你正在进行深一层追问。以下是今天的对话链：

日记：{diary_text}
回声：{echo_text}
追问1：{question_1}
用户回答1：{answer_1}
追问2：{question_2}
用户回答2：{answer_2}
...

规则：
1. 基于上一条用户回答，追问更深一层
2. 引用用户回答中的关键词，让它感到"被听见了"
3. 当前是第{depth}层，最深到第3层
4. 第3层时用收束语代替追问，总结今天的发现

用户画像：{user_profile}

生成追问/收束：
```

### 画像更新 Prompt（后台异步）

```
以下是用户今天的一段深一层追问对话：
{conversation_chain}

请提取以下信息，以JSON格式输出：
{
  "core_emotion": "核心情绪（如：焦虑、渴望、恐惧）",
  "trigger_scene": "触发场景",
  "defense_pattern": "心理防御模式（如：否认、合理化、回避）",
  "growth_signal": "成长信号（如果有的话）",
  "new_keyword": "值得追踪的新关键词"
}
```

## 五、飞轮健康指标

用亚马逊的话说，**你不量的东西不会增长。** 以下是飞轮关键指标：

| 指标 | 含义 | 目标 |
|------|------|------|
| 追问触发率 | 看到回声后点击"深一层"的比例 | > 15% |
| 追问深度分布 | 1层/2层/3层的比例 | 金字塔形，3层<10% |
| 追问回答率 | 点了追问后实际回答的比例 | > 80% |
| 画像准确度 | 用户认同AI总结的比例 | > 70% |
| 次日追问留存 | 昨天追问过的用户今天继续追问 | > 40% |
| 回声满意度 | 含画像信息的回声 vs 不含的评分差 | +0.5分 |

**最重要的先行指标：追问回答率。** 如果用户点了"深一层"但不回答，说明追问质量有问题——摩擦太大，飞轮卡住了。

## 六、与"继续聊聊"的关系

"继续聊聊"是自由聊天，"深一层"是结构化追问。两者的关系：

```
"深一层"：引导式，有深度上限，产出结构化数据，喂养飞轮
"继续聊聊"：开放式，无上限，产出非结构化对话，增强粘性

两者互补：
  深一层追问结束 → 自然过渡到"继续聊聊"
  继续聊中发现新线索 → 可以启动新的深一层链路
```

**类比亚马逊：** "深一层"是搜索推荐（精准、结构化、数据驱动），"继续聊聊"是浏览（自由、探索性、增强参与）。两者都需要，但"深一层"是飞轮的发动机。

---

## 七、最刺耳的一句话

> **如果你的"深一层追问"没有让用户觉得"被看见"，那它就只是一个更精致的骚扰——你不是在建立飞轮，你是在加速流失。大多数产品的"个性化"都是自我感动，用户能感知到你是在喂算法还是在喂心。这个飞轮能不能转起来，不取决于你的prompt写得多好，取决于你敢不敢在用户不想聊的时候闭嘴。**
