# 深一层追问 · Steve Jobs 视角

> "Design is not just what it looks like and feels like. Design is how it works."
> 设计不只是外观和感觉，设计是它如何运作。

---

## 一、核心原则：一个按钮的哲学

iPhone 只有一个 Home 键。
深一层追问，只需要一个动作。

**不要问用户"想从哪个角度深入"。**
用户不知道。用户来这里是被引导的，不是来选择题的。

---

## 二、最少交互设计

### 交互只有一步

```
[ 回声卡片 ]
   ↓
  用户看到回声，感到"被触动但还想多说点"
   ↓
  轻点卡片，或点一个「↓」符号
   ↓
  回声自然延伸，像对话一样继续
```

### 为什么不是一个按钮

按钮意味着"决定"。用户不需要做决定。

最好的交互是**没有交互**——是**顺势而为**。

当用户盯着回声看超过 2 秒，或者轻点卡片，就触发深一层。
不是按钮。是**对注意力的回应**。

## 三、UI 设计

### 当前状态

```
┌─────────────────────────────┐
│  🌙 今天有点累...            │
│                              │
│  AI 回声：                   │
│  "累了就休息，明天继续..."    │
│                              │
│  [换一句]  [继续聊聊]        │
└─────────────────────────────┘
```

### 设计后

```
┌─────────────────────────────┐
│  🌙 今天有点累...            │
│                              │
│  AI 回声：                   │
│  "累了就休息，明天继续..."    │
│          ↓                   │
│  "但你有没有想过，            │
│   为什么最近总是累？"         │
│                              │
│         [继续 ↓]             │
└─────────────────────────────┘
```

### 关键设计细节

1. **「↓」符号** - 不是按钮，是方向。暗示"往下走"
2. **回声直接延伸** - 不是新卡片叠加上去，是同一段文字生长
3. **最多 3 层** - 第一层是回应，第二层是追问，第三层是洞察。三声回响，足够了
4. **「继续 ↓」只在还有深度时出现** - 到底了就消失，不给空选择

## 四、Prompt 设计

### 第一层（原始回声）

```
用户写了：{日记内容}

你是用户内心的温暖回声。
用 1-2 句话，回应用户的感受。
不要分析，不要建议。只是看见他。
```

### 第二层（深一层）

```
用户写了：{日记内容}
你已经回应：{第一层回声}

在刚才的回声基础上，往深处走一步。
用一个温柔的问题，帮用户看见自己没注意到的东西。
不要解释，不要分析。只问一个问题。
```

### 第三层（再深一层）

```
用户写了：{日记内容}
回声序列：{第一层} → {第二层}

再深一层。这次不是问问题。
用一句话，说出用户心里有但说不出的那个东西。
像一面镜子，让他看见自己。
```

### 为什么是三层

- 第一层：被看见
- 第二层：看见自己
- 第三层：看见真相

**三声回响。不多不少。**

---

## 五、深度限制

### 硬限制：3 层

不是技术限制，是**体验限制**。

超过 3 层，就变成了"心理咨询"，不是"日记回声"。
用户来这里是为了被温暖，不是被剖析。

### 软限制：情感边界

如果第二层已经触及用户可能不舒服的地方，直接停。

判断标准：第二层回声如果让用户"皱眉"，第三层就不要出现。

---

## 六、与"继续聊聊"的关系

### 它们是不同的入口

| 功能 | 触发方式 | 本质 |
|------|----------|------|
| 深一层 | 轻点回声 / 「↓」| 在同一个思绪里往下挖 |
| 继续聊聊 | 点按钮 | 开启新的对话分支 |

### 设计原则

- 深一层是**纵向**的，继续聊聊是**横向**的
- 深一层在回声卡片内完成，不跳转页面
- 继续聊聊打开聊天界面，是全新的交互

**它们不冲突。一个是回声的延伸，一个是对话的开始。**

## 八、最少交互，最大触动

### Jobs 的答案

**最少的交互**：用户只需要看。看到想深入，轻点一下。
**最大的触动**：第三层回声，说出用户心里有但说不出的话。

这就是设计的秘密——

**不是让用户做更多，而是帮用户感受到更多。**

---

## 最刺耳的一句话

**"如果你需要教用户怎么用深一层，那这个设计就失败了。"**

好的设计不需要说明书。用户看到回声，自然想往下走。如果他们不知道可以点，或者点了不知道会发生什么，那是你的问题，不是用户的问题。

**别把简单的事情复杂化。一个方向键，三层回响，够了。**
