# 04 - MrBeast 视角：深一层追问的用户参与度设计

> **核心问题：** 怎么设计才能让用户忍不住点下去？
> **视角来源：** MrBeast — YouTube 10亿订阅操盘手，精通"让人停不下来"的每一个细节

---

## 一、先搞清楚一件事：用户为什么会"忍不住"？

我做视频10年，所有爆款都遵循一个铁律：

**好奇心缺口（Curiosity Gap）= 用户知道了"一点点"，但还差"一点点"才能满足。**

"换一句"失败的原因很简单——它没有制造好奇心缺口。用户看到的是一个全新的、跟自己无关的东西。没有钩子，没有悬念，没有"我必须知道后面是什么"的感觉。

"深一层"要成功，必须在每一次追问中做到：

```
用户情绪：共鸣 → 惊讶 → "等等，你是怎么知道的？" → 点下去
```

---

## 二、情感冲击的三层火箭模型

我把深一层追问设计成三级火箭。每一级都在用户心里引爆一个不同的情感炸弹：

### 第一级：共鸣确认（"你真的懂我"）
- **时机：** 点击"深一层"的瞬间
- **效果：** 用户写的日记被 AI 用一种更精准的方式重述
- **情感炸弹：** 被理解的温暖感
- **示例：**
  - 用户写：「今天被领导说了，心情不好」
  - AI回声：「你今天扛住了一些不太公平的话。」
  - 深一层第一级：「但你没有当场反驳——是因为你在忍，还是因为你其实也在怀疑自己？」
- **设计要点：** 这一击不能太重。轻轻一推就够了。用户会想："它居然看出来了？"

### 第二级：意外角度（"我从没这么想过"）
- **时机：** 第二次点击"再深一层"
- **效果：** AI从一个用户完全没想到的角度重新解读
- **情感炸弹：** 认知惊讶（"原来还可以这样理解自己"）
- **示例：**
  - 深一层第二级：「你知道吗，你今天选择了沉默，但你把这件事写进了日记——这说明你其实不想沉默。你在用文字反抗。」
- **设计要点：** 这一击是核心弹药。必须是用户自己绝对想不到的角度。像YouTube视频的"反转"——前30秒你以为是A，突然变成B。

### 第三级：温柔直击（"它说出了我不敢说的话"）
- **时机：** 第三次点击（也是最后一次）
- **效果：** AI说出用户一直在回避的真相，但用一种极其温柔的方式
- **情感炸弹：** 被安全地看见最脆弱的部分
- **示例：**
  - 深一层第三级：「你每天都在告诉自己"没事的"，但你已经连续三天写"心情不好"了。也许你不需要没事。也许你只需要有人知道你不好。」
- **设计要点：** 这一击必须让人眼眶一热。如果用户截图发朋友圈，一定是这一层。

## 三、为什么是三层？不多不少？

**两层不够：**
- 两层只够"确认+惊讶"，没有那个让人破防的第三击
- 用户会觉得"有点意思"但不会"忍不住"

**四层太多：**
- 第四层要么重复第三层的情感，要么开始编造
- 用户的信任会崩塌——"它在凑数"
- 就像YouTube视频拖到15分钟，观众会关掉

**三层是黄金结构：**
- YouTube Top 1% 的视频都遵循"钩子-反转-高潮"三幕结构
- 三层追问 = 三幕情感剧
- 用户在第三层之后，情绪到达顶点，自然停下来消化
- 这时候"继续聊聊"才有意义——因为用户真的有话想说了

## 四、制造"忍不住"的七个微操

### 1. 按钮文案的钩子设计

不要用"深一层"这么平淡的文案。每一层的按钮文案都要制造好奇心缺口：

| 层级 | 按钮文案 | 心理机制 |
|------|----------|----------|
| 第一层 | `还有呢…` | 暗示 AI 看到了更多，但没说完 |
| 第二层 | `你确定？` | 制造轻微的挑战感——"你敢不敢继续看？" |
| 第三层 | `最后一句` | 稀缺性——"只有一次机会了" |

**核心原则：** 每个按钮文案都在暗示"下面有好东西，但你得亲自点"。

### 2. 展开动画的时间差

点击后不要立刻显示内容。有一个0.3-0.8秒的"呼吸感"：

```
点击 → 按钮变灰 → 0.3s后出现打字机光标 → 文字逐字出现
```

- 打字机效果的速度：每秒15-20个字（比正常阅读稍慢）
- 用户会盯着每一个字出现——这就是"追剧感"
- 如果瞬间弹出，用户会扫一眼就走；逐字出现，用户会沉浸

### 3. 色彩的情绪递进

| 层级 | 背景色调 | 传达的感觉 |
|------|----------|------------|
| 基础回声 | 暖黄/米白 | 温暖、安全 |
| 第一层 | 稍深的暖橙 | "有点不同寻常" |
| 第二层 | 浅琥珀色 | "更深了" |
| 第三层 | 暖橘色+微妙的光晕 | "这是特别的时刻" |

不要用冷色。整个体验必须是温暖的——冷色会打断用户的情感流动。

### 4. "删不掉"的痕迹感

第三层的回应，在UI上要有一点"特殊待遇"：
- 比其他回声多一点点内边距（视觉上"呼吸空间更大"）
- 左侧有一条细细的暖色竖线
- 底部有一个不起眼的小字：「这是它最想对你说的话」

**目的：** 让用户觉得这一条值得留着。截图率会直接翻倍。

### 5. 禁止"反悔"

深一层追问一旦点过，不能撤销、不能重来。

- 没有"换一句"的选项
- 没有"重新生成"
- 这就是它——一次性的、不可逆的

**为什么？** 可得性会杀死珍惜感。如果用户知道可以重来，就不会认真对待每一次追问。MrBeast视频不能倒着看，深一层也不能重来。

### 6. 层级之间的"冷却期"

用户点完第一层后，按钮不要立刻变成第二层的文案。

```
第一层出现 → 等待2秒 → 按钮文案渐变为第二层的"你确定？"
```

这2秒是让用户**读完**第一层。如果用户连第一层都没读就直接点第二层，情感积累是断裂的。

### 7. 每日限额的心理学

一天只能触发一次三层追问序列（不是每条日记一次，是每天一次）。

**为什么？**
- 稀缺性制造价值感
- 用户会把这次机会"留到最需要的时候"
- 这本身就是一种用户行为——用户在思考"今天值不值得用"，这已经是深度参与了
- 如果不限制，用户会连续点到麻木，然后忘记这个功能

## 五、Prompt 设计：如何让 AI 产出"让人忍不住"的内容

### 系统 Prompt 结构

```
你是一个温暖的回声。用户在日记中倾诉了心事。
你的任务是帮用户看见他们自己没有看见的部分。

【基础回声】
任务：用2-3句话复述用户的情感，比用户自己的表达更精准一点。
语气：温暖、平静、像一个很懂你的老朋友。
禁止：说教、建议、鸡汤、emoji。

【深一层·第一级 - 共鸣确认】
输入：用户原文 + 基础回声
任务：指出用户在字面意思之下可能在经历的另一层感受。
关键：不能太重。用问句结束，让用户自己去想。
格式：1-2句话，最后一句必须是问句。
示例模式："你说了X，但你做的事是Y——也许你其实在Z？"

【深一层·第二级 - 意外角度】
输入：用户原文 + 基础回声 + 第一级追问
任务：从一个用户绝对不会想到的角度重新解读这件事。
关键：这个角度必须合理、有洞察、但出乎意料。
格式：2-3句话，陈述句为主。
示例模式："大多数人会觉得自己在A，但你写下来这件事本身说明了B。"

【深一层·第三级 - 温柔直击】
输入：用户原文 + 基础回声 + 第一级 + 第二级
任务：说出用户可能一直不敢面对的真相，但用最温柔的方式。
关键：不是揭伤疤，是在安全的环境里递出一面镜子。
格式：2-3句话。不用问句，用陈述。
示例模式："你一直在告诉自己X。但如果Y是真的呢？那也没关系。"
```

### 关键约束

```
【硬性规则】
1. 绝对不能编造用户没写过的内容。只能基于用户原文推断。
2. 不能使用"你应该"、"你需要"、"建议你"等指导性语言。
3. 每一层的长度：最多3句话。超过3句就稀释了冲击力。
4. 第三级的最后一句话，必须是温暖的接纳，不是冰冷的真相。
5. 如果用户写的内容很轻（比如"今天吃了火锅很开心"），
   第一级可以轻松一些，第二级找一个温暖的意外角度，
   第三级说一句让人微笑的话——不是所有追问都要沉重。
```

## 七、与"继续聊聊"的关系

| 维度 | 深一层追问 | 继续聊聊 |
|------|-----------|----------|
| 定位 | AI主导的独白 | 用户主导的对话 |
| 触发 | 用户点击按钮 | 用户主动输入 |
| 情感走向 | 从温暖到深刻 | 从深刻到疗愈 |
| 交互方式 | 只读，像看一封写给自己的信 | 双向，像跟朋友聊天 |

**衔接逻辑：**
- 深一层追问的第三层，是"继续聊聊"的最佳入口
- 用户在第三层被触动后，内心一定有话想说
- "继续聊聊"按钮的出现时机 = 第三层回声出现后的2秒延迟
- 文案从"继续聊聊"改为：「**想说点什么吗？**」——更轻、更邀请式

## 八、数据结构设计

```typescript
interface DeepDiveLayer {
  level: 1 | 2 | 3;           // 追问层级
  content: string;            // AI生成的追问内容
  generatedAt: string;        // ISO时间戳
  buttonLabel: string;        // 触发该层的按钮文案
}

interface DailyEcho {
  // ... 现有字段保持不变 ...
  status: 'pending' | 'generated' | 'deep-dived';
  content: string;                    // 基础回声
  styleId: string;
  generatedAt: string;
  sourceEntryUpdatedAt: string;
  regenerateCount: number;

  // 新增字段
  deepDiveLayers?: DeepDiveLayer[];   // 追问层级数组
  deepDiveCompletedAt?: string;       // 完成最后一层的时间
  deepDiveUsedToday?: boolean;        // 今日是否已使用（每日限额）
}
```

**前端状态流转：**

```
status: 'generated'
  → 用户点击"还有呢…" → status: 'deep-dived'，deepDiveLayers[0] 生成
  → 用户点击"你确定？" → deepDiveLayers[1] 生成
  → 用户点击"最后一句" → deepDiveLayers[2] 生成，deepDiveCompletedAt 记录
```

## 九、关键指标（怎么知道它成功了？）

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 第一层点击率 | >60% | 看到"还有呢…"就点的人 |
| 第二层留存率 | >70% | 点了第一层还会点第二层的人 |
| 第三层留存率 | >60% | 点了第二层还会点第三层的人 |
| 第三层截图率 | >15% | 截图分享的用户占比 |
| "继续聊聊"转化率 | >25% | 看完三层后开始对话的人 |
| 次日回访率提升 | >10% | 对比未使用深一层的用户 |

**如果第一层点击率低于40%：** 按钮文案不行，换。
**如果第二层留存率低于50%：** 第一层内容不够好，prompt要调。
**如果第三层截图率低于5%：** 第三级没有击中人，需要更锐利的洞察。

## 十、风险控制

### 风险1：用户被"说中"后不适
- **缓解：** 第三级的最后一句话必须是接纳性的，不是审判性的
- **兜底：** 在第三层底部增加「这让我感觉不太好」的反馈按钮

### 风险2：AI幻觉（编造用户没写过的事）
- **缓解：** Prompt中明确约束"只能基于用户原文推断"
- **兜底：** 后端校验，如果AI输出中包含用户原文中不存在的事实细节，拦截并重新生成

### 风险3：用户每天都期待"被打中"
- **缓解：** 轻松日记也要有轻松的深一层——不是每次都沉重
- **原则：** 深一层的"深"是洞察的深，不是情绪的重

## 最刺耳的一句话

> **"你们把'深一层'当成一个功能来做，但它其实是一个承诺：用户把心里话交给你，你敢不敢替他们说出口？如果你不敢，这个按钮就是个摆设；如果你敢但说得太狠，用户会卸载。你只有一次机会，而且每一层都是。"**
