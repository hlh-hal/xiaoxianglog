应用主要运行流程

用户完成登录后，可记录、整理、回顾并同步自己的私人日记

1打开应用进入小象日志 Android 客户端
›
2账号登录使用邮箱密码，或已绑定的微信身份登录
›
3记录日记编辑文字、添加图片、标签与主题
›
4保存与同步优先保存在本地，登录后同步至本人账号
›
5整理与回顾浏览历史、搜索内容、查看回收站
所有日记数据都归属于小象日志主账号（userId）；微信只作为一种登录身份，不复制或迁移日记数据。

微信登录与新用户注册流程

仅 Android 客户端显示微信登录入口，微信授权凭证由服务端安全交换

1点击“微信登录”跳转微信完成授权，返回一次性授权 code
微信身份已绑定

直接登录原账号

服务端找到对应微信身份，返回同一个小象日志 userId，进入日记首页并读取该账号原有数据。

微信身份未绑定

完成小象账号注册

验证一个未注册邮箱，设置密码、昵称并同意用户协议与隐私政策，再创建主账号和微信身份。

小象日志

已注册用户绑定微信流程

账号归属以已登录邮箱账号为准，绑定前必须验证当前账号邮箱

1邮箱登录使用现有邮箱和密码进入原账号
2进入个人信息查看微信绑定状态并点击“绑定微信”
3验证当前邮箱验证码只发送到当前账号邮箱
4微信授权在微信客户端确认授权并返回应用
5完成绑定微信身份关联到当前 userId
绑定结果：用户昵称、头像、邮箱和历史日记均保持不变。若该微信已属于其他账号，则拒绝绑定，不自动合并两边数据。解绑同样需要当前邮箱验证码，解绑不会删除账号或日记。
