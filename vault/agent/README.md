# Agent 记忆规则

这里存放给后续 Codex/Agent 使用的持久规则、决策和踩坑记录。

## 什么时候更新

- 任务产生了长期有效的决策、阻塞项、负责人、外部链接或复用步骤。
- 发现了容易重复踩坑的问题。
- 用户明确要求“记住”“以后都这样”“下次先看这里”。
- 本次任务修改了代码、部署配置、测试、同步逻辑、认证、通知、PWA、Android、线上配置或用户可见流程，并且这些变化会影响下次接手判断。
- 本次任务改动超过 3 个文件、产生了新的验证命令、留下待办/风险，或修复了高影响 bug。

## 写到哪里

- 待办和阻塞：`vault/TODO.md`。
- 项目背景、当前状态和最近重大变更：`vault/projects/xiaoxiang-log.md`。
- Agent 规则、踩坑、流程问题：`vault/agent/`。
- 当日摘要和临时复盘：`vault/notes/daily/YYYY-MM-DD.md`。
- 旧的 `WORKLOG.md` 可以保留索引，但不能替代 `vault/`。

## 什么时候不更新

- 只是一次性问答。
- 没有长期价值的小修。
- 内容包含密钥、私人账号、敏感隐私或可从代码直接读出的瞬时状态。

## 写法

- 先找已有相关笔记并追加或修订。
- 标明日期，必要时写清来源和影响范围。
- 用简短清楚的中文，避免把聊天记录整段搬进来。
