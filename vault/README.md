# Vault

这是小象日志项目的共享工作记忆，用来保存跨会话仍然有价值的上下文。

## 目录

- `TODO.md`：长期待办、阻塞项、下次优先事项。
- `projects/`：项目背景、里程碑、重要决策和接手说明。
- `people/`：协作者、负责人和工作偏好。
- `agent/`：Agent 工作规则、决策记录和踩坑记录。
- `notes/`：每日摘要、草稿、复盘和临时笔记。

## 使用方式

开始复杂任务前先读 `TODO.md`、`agent/memory-workflow.md` 和相关项目笔记。任务结束前，如果产生了新决策、阻塞、风险、负责人、验证命令、踩坑记录或下次接手信息，就更新对应笔记。

如果一次任务改动超过 3 个文件，或涉及代码、部署配置、测试、同步逻辑、认证、通知、PWA、Android、线上配置、用户可见流程，必须检查并更新本知识库。不要只更新 `WORKLOG.md`。

不要记录密钥、真实 token、私密账号密码、数据库文件或用户隐私数据。
