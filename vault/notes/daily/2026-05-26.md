## 注意

- 纯网页/PWA 仍没有真正的远程 Push 订阅；好友申请通知依赖应用被打开或恢复运行时的前端轮询。当前修复目标是“已有通知权限时能弹出系统通知”，尤其解决 Android 添加到桌面后测试通知/本地提醒不弹的问题。
- 历史日志批量同步仍逐篇写文件以保证每篇都经过后端写入校验，但 manifest 和目录扫描已批量化；如果 Android 真机仍慢，下一步优先考虑把批量写入下沉到 Capacitor 插件侧，减少 JS/native 往返。
- Android Chrome / 移动 PWA 的 File System Access 文件夹写入不可依赖；后续不要再在移动网页端提示“选择文件夹后直接同步成功”，移动网页端交付物应是可下载 ZIP，本地解压后得到同样的文件夹结构。
- 2026-05-26 晚些时候按用户要求调整策略：Android Chrome / 移动 PWA 不再按 UA 一刀切走 ZIP；只要浏览器暴露 `showDirectoryPicker()`，就先尝试真实文件夹同步。选择目录后会写 `.xiaoxiang/write-probe-*.txt` 探针并读回校验，成功后才保存目录授权并继续批量同步；探针失败时不会显示同步成功。
