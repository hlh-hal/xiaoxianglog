## Android App 编辑器选区白块修复

- 来源：用户截图反馈，Android App 编辑界面选中文字时，选区手柄下方出现白色矩形底；网页端同场景正常。
- 判断：问题更像 Android WebView 原生文本选区手柄/选区合成层在深色主题下回落到白色底，不是网页端选择菜单、底部格式工具栏或主题背景本身。
- 改动：`src/pages/Editor.tsx` 给正文滚动容器增加 `diary-editor-scrollport` 和 `data-text-selection-active`，并通过 `--diary-editor-background` 暴露当前编辑背景色；深蓝纯色主题会使用 `selectedTheme.backgroundColor` 作为选区态背景兜底。
- 改动：`src/index.css` 增加仅限 `html[data-platform="android"] .diary-editor-scrollport` 的样式，保持文字可选中，同时对 ProseMirror 设置透明背景、绘制隔离、tap highlight 透明和 Android-only selection 颜色，降低原生选区手柄被合成出白底的概率。
- 未改动：未调整滚动 guard、IME composition、图片内联工具栏、保存/同步/API/数据库逻辑。
- 验证：`npm run lint` 通过；`npm run build` 通过，仅保留既有动态导入和 chunk size 提醒；`npx cap sync android` 已完成 Web assets 同步。
- 风险/下一步：仍需要在 Android 真机或模拟器上长按拖选深蓝主题正文，确认白块消失，并确认复制/分享/全选菜单、键盘、底部工具栏和主题栏不受影响。

## 日记写作用时思考上限调整为 3 分钟

- 来源：用户补充写日志过程中会停下来思考一个点，期间没有输入内容，但应计入写作时间；单段思考上限为 3 分钟，超过视为离开写作。
- 改动：`src/utils/dailyEchoCompletionStats.ts` 将 `WRITING_ACTIVITY_WINDOW_MS` 从 90 秒调整为 180 秒，继续按相邻写作活动间隔 `min(间隔, 180s)` 累计，保留分钟四舍五入与最小 1 分钟展示。
- 边界：`blur`、`visibilitychange:hidden`、`pagehide` 仍会立即暂停，不把切后台/离开页面后的时间计入。
- 测试：`tests/daily-echo-completion-stats.test.ts` 新增 2 分 30 秒思考完整计入、10 分钟空档只计 3 分钟，并保留跨会话暂停、连续 5 分钟、四舍五入等场景。
- 验证：`npm run test:daily-echo-completion`、`npm run lint`、`npm run verify:daily-echo-writing-time` 均通过；浏览器验证中思考用例 `thinkingStoredSeconds=150`。
