## 编辑器移动端选区白块修复

- 来源：用户截图反馈，正文编辑时 Android 输入法/选区光标下方出现白色矩形块。
- 改动：在 `src/index.css` 的 `.ProseMirror` 样式里明确设置 `caret-color`、禁用 tap highlight，并为 `.ProseMirror::selection` / `.ProseMirror *::selection` 指定小象绿色半透明选区色，避免浏览器回落到蓝色/白色系统绘制。
- 验证：已执行根目录 `npm run lint` 和 `npm run build`，均通过；build 仅保留既有 chunk size / dynamic import 提醒。
- 注意：本次未推送、未部署用户端；白块属于移动端原生选区绘制问题，后续如真机仍复现，可继续检查 Android WebView 版本和 contenteditable 祖先层的 mask/backdrop/transform 影响。

## 编辑器选区手柄白底与拖选流畅度追加修复

- 来源：用户补充深色主题截图，选区拖拽手柄外仍有白色矩形底，视频反馈选中文字不流畅。
- 改动：在 `src/pages/Editor.tsx` 中编辑态/文本选区态不再给正文滚动容器套 `mask-image`，避免 Android 原生选区手柄被 masked stacking context 合成出白底；同时取消拖选移动和 `selectionchange` 过程中的实时多帧 scroll guard 调度，仅保留松手/滚动后的兜底修正，减少拖选时的布局读取与滚动写入。
- 验证：追加改动后再次执行根目录 `npm run lint` 和 `npm run build`，均通过；build 仍仅有既有 chunk size / dynamic import 提醒。

## 编辑器滚动时白色长方块追加修复

- 来源：用户视频反馈，上下活动/编辑时正文中出现白色长方形块，影响编辑体验。
- 判断：抽帧后确认白块位于 caret/输入位置，不是主题背景露底，更像 Android IME 组合输入临时层或 inline 白色背景残留。
- 改动：`src/index.css` 里覆盖 ProseMirror 内部临时白色 inline background 为透明，并在 IME 组合态关闭 transition；`src/pages/Editor.tsx` 里 compositionstart 只做一次滚动锁定、compositionupdate 不再反复锁滚动，compositionend 延迟移除组合态 class，减少输入法重绘残影与卡顿。
- 验证：再次执行根目录 `npm run lint` 和 `npm run build`，均通过；已生成本地验证截图 `C:\Users\ASUS\AppData\Local\Temp\xiaoxiang-test-proof\test-proof.png`。

## 日记完成卡片写作用时统计修正

- 来源：用户反馈完成卡片“用了 X 分钟”在分段写作场景下不准确，例如写一部分退出，隔一小时或数小时后回来继续写，会把中间空档误算进用时。
- 改动：`src/utils/dailyEchoCompletionStats.ts` 的 `getActiveWritingMinutes()` 不再取“本次会话从第一次输入到保存的跨度”，只基于 `elapsedMs` 的累计活跃写作时间；仍保留 30 秒 activity window、blur/visibility/pagehide 暂停、跨会话 `activeWritingSeconds` 基线累计。
- 测试：更新 `tests/daily-echo-completion-stats.test.ts`，覆盖长间隔不计入分钟、跨长休息分段写作累计、已有 14 分钟基线继续累计到 15 分钟。
- 验证：`npm run test:daily-echo-completion` 通过；`npm run lint` 通过。
