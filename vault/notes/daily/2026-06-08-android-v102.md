# 2026-06-08 Android v1.0.2 修复与发布

## 背景

用户真机反馈 Android APK 有三类问题：

- 安装页显示默认蓝色图标，没有加载小象日志应用图标。
- 小米安装器提示“未查询到此应用的 ICP 备案信息”，但备案后台显示小象日志已通过备案。
- 登录后社区、头像、图库中的上传图片显示为 broken image。

## 本次处理

- Android 版本升到 `versionName 1.0.2` / `versionCode 3`，包名继续保持 `com.xiaoxiang.diary`。
- 使用 `public/icons/xiaoxiang-pwa-512.png` 生成 Android `mipmap-*` launcher 图标，并替换启动页 `splash.png`，避免安装页和启动页继续显示默认图。
- 修复 `capacitor.config.ts`、Android `strings.xml` 中的应用名为 UTF-8 `小象日志`。
- 修复媒体地址解析：APK 中 `/api/uploads/...`、`/uploads/...` 会解析为 `https://www.xiaoxianglog.cn/...` 绝对地址，避免 WebView 请求到本地域名。
- 后端社区帖子返回前调用 `repairLegacyImageUrls()`，补上历史 data URL 图片修复。
- 更新 `public/app-update.json`、`docs/app-update.json` 和官网版本展示到 `1.0.2`。
