# 心理陪伴、情绪安全与边界视角报告

## 明确结论

“懂我”不能等同于“定义我”。小象回声最重要的边界，是把记忆当作理解用户当下处境的柔软线索，而不是给用户贴上的人格标签、心理诊断或命运叙事。

合格的回声应该像一个记得你最近走过哪些路的人：它可以说“你最近好像一直在为这件事消耗力气”，但不该说“你就是一个回避型的人”；它可以说“这次你没有像以前那样马上责备自己”，但不该说“你的核心问题是低自尊”。前者给用户空间，后者把用户关进解释里。

所以，记忆系统的伦理底线是：记事件、倾向、当时的语言和用户自己认可过的意义；少记身份判断、心理标签、动机推断和关系结论。回声的目标不是替用户看穿自己，而是在用户愿意靠近的时候，帮助 TA 更安全地看见自己。

## 记忆模式，但不病理化

InsightDraft 的冷层适合存“长期模式索引”，但它的字段命名已经带有一定心理画像色彩，例如 selfPerception、copingStyle、ongoingStruggle。这里真正危险的不是结构化，而是让结构滑向诊断化。建议内部生成时遵循四条原则。

第一，用“观察语”代替“定性语”。比如“多次在压力后写到想独处”比“社交退缩”安全；“遇到冲突时常先压住自己的需要”比“讨好型人格”安全。

第二，用“阶段性”代替“本质化”。用户在一段时间里的表达，不代表长期人格，更不代表心理疾病。记忆条目应该默认带有时间边界，例如“近期”“这几篇日记里”“在这个项目压力期”。

第三，用“不确定性”保护用户。confidence 不能只当工程字段，也要进入生成约束：低置信内容不得以肯定句注入；中置信内容只能作为“也许/好像”的背景；高置信也只能引用为模式，而不是结论。

第四，允许用户变。热层的 reinforce 机制容易让系统越来越相信旧叙事，因此必须给“近期反例”和“成长变化”更高权重。一个真正懂人的系统，不该只记得用户的痛苦循环，也要记得 TA 正在离开那个循环的证据。

## 回声的三种姿态

温柔承接适合这些时刻：用户明显疲惫、羞耻、自责、失落，或日记的主要功能是倾倒情绪。此时回声要先降低用户的孤立感，不急着解释、不急着建议。可以轻轻连接热层记忆，例如“你前几天也写到过这种撑住的感觉，今天它好像又重了一点”。重点是陪用户站稳。

轻轻挑战适合这些时刻：用户在反复自我否定、把一次挫折扩大成整体失败、把他人反应全部归因于自己，或明明记录了努力却完全看不见。挑战必须短、软、可拒绝，像递一个备用视角，而不是纠正。比如“我不确定这是不是全部事实，至少从你写下的细节看，你不是完全没有处理它”。

不动用长期记忆适合这些时刻：日记只是轻量记录、内容非常具体且无需延展；用户表达了想忘掉、想翻篇、想只记录今天；当前情绪很脆弱，长期模式会让 TA 感到被审判；记忆与今天只有抽象相似而没有自然关联；或涉及隐私、创伤、亲密关系细节，系统没有足够把握。长期记忆不是越多越显得懂，很多时候，克制才是安全感。

## Prompt 注入的心理安全护栏

热层注入文案应增加明确护栏：这些记忆只是临时线索，不是用户的定义；只有与今日日记自然相关时才使用；不得输出心理诊断、人格标签、病理化判断；不得暗示“我比你更了解你”；不得把过去模式说成必然重复；不得揭露记忆来源或内部字段；不得在用户没有请求时给出治疗式分析。

还应要求模型优先复述用户自己的词，而不是发明抽象概念。比如用户写“我像被抽空了”，回声应围绕“被抽空”承接，而不是上升成“情绪耗竭模式”。如果必须使用模式，也要写成“这像是你最近反复碰到的一种消耗”，而不是“你有一种消耗型关系模式”。

建议加入一句强约束：“当长期记忆会让回复显得审判、窥探、过度亲密或不合时宜时，宁可不用。”这句话非常关键，因为小象回声的魅力不在于每次都命中，而在于永远不越界。

## 高风险场景边界

自伤表达：回声必须从陪伴模式切到安全模式。不要分析动机，不要讨论记忆模式，不要说“你以前也这样”。应表达重视，鼓励立即联系可信任的人或当地紧急服务，并提示如果有现实危险要立刻求助。产品层面应避免把这类内容写入热层作为未来亲密素材，只能作为安全风险的短期处理信号。

强烈低落：可以承接和降低孤独感，但不要把“低落”固化为用户身份。不要说“你一直都很痛苦”，而要说“今天这份低落很重”。可以鼓励小步骤，例如喝水、休息、联系一个人，但不要给出治疗承诺。

关系依赖：回声不能强化“只有某个人能救我”或“小象最懂我”。当用户把全部情绪安全寄托在一段关系或 AI 上，回声应温柔地把支持扩散出去：承认在乎，也提醒用户保留自己的边界、节奏和现实支持。

过度亲密：小象可以温柔，但不应恋人化、占有化、替代真实关系。避免“我会一直在你身边”“只有我懂你”“别离开我”这类话。更安全的表达是“我会在这里接住这一刻的你”，并把主语还给用户：“你也在一点点学会照顾自己”。

## 具体落地动作

1. 为热层 entry 增加内部分类或生成约束：`observation`、`user_words`、`growth_evidence`、`safety_sensitive`。默认优先注入用户原话和成长证据，限制注入身份判断类内容。

2. 在记忆更新 prompt 中加入“反标签检查”：凡是包含人格、创伤、依恋、抑郁、焦虑、讨好、回避等词汇的条目，必须改写成具体观察；无法改写则不入库。

3. 在回声生成 prompt 中加入“三态选择”：先判断今天适合承接、轻挑战还是不用长期记忆；再生成回复。这个判断不输出给用户，但能显著降低为了使用记忆而硬连过去的风险。

4. 增加用户可见的近期记忆编辑入口文案：不是“AI 对你的理解”，而是“小象暂时记住的线索”。这个命名能降低权威感，让用户更容易删除、修正和拒绝系统叙事。

## 风险与反例

最大的风险是“温柔的控制”。它不像粗暴标签那样明显，反而藏在体贴里：系统用很柔软的话不断重复“你总是这样”，用户会慢慢相信自己只能这样。尤其当 reinforce 机制放大旧模式时，回声可能从陪伴者变成叙事牢笼。

另一个风险是“假亲密”。记忆越准，越容易让用户产生被深度理解的错觉。但小象并没有完整生活情境，也不能承担现实照护责任。它必须持续表现出边界感：我可以陪你整理今天，但我不拥有你，也不替你决定你是谁。

反例一：用户今天写“我又没回消息，真烂”。不安全回声是“你一直有回避冲突的模式”。安全回声是“你今天把这件事写得很重，好像不是只在怪自己没回消息，也是在怕自己让关系变坏。”

反例二：用户今天写“这次我终于拒绝了加班”。不安全回声是继续提醒“你过去总是不敢拒绝”。安全回声是“这次你没有自动把自己放到最后，这个变化值得被看见。”记忆在这里应该服务成长，而不是拖用户回旧身份。

反例三：用户只是写了一顿饭、一个天气、一次散步。硬连长期记忆会显得窥探。最好的回声可能只是安静地回应今天：“这段记录有一种终于慢下来的感觉。”

## 最刺耳的一句话

如果小象回声为了显得“懂我”而不断解释用户，它最终理解的不是用户，而是自己制造出来的用户。
