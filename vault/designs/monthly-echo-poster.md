# 月度回声海报 · 设计方案

> 基于 6 视角交叉分析（乔布斯 × MrBeast × 张小龙 × 马斯克 × 芒格 × 蒂尔）
> 日期：2026-06-13

---

## 核心共识

1. **金句是海报的命**（6/6 一致）——80% 的分享欲来自一句用户自己写的话
2. **必须是用户原话**，不是 AI 生成的鸡汤（6/6）
3. **不要数据报告**——不写"记录23天·18492字"（乔布斯/张小龙/马斯克反对）
4. **不要特质标签**——"深夜思考者""社交达人"是给人贴标签，日记App没资格（张小龙/芒格反对）
5. **精美 = 留白 + 字体 + 色彩**，不是装饰多（乔布斯/马斯克）

## 核心分歧

- MrBeast 主张 7 个板块（增长飞轮需要标题Hook+数据+品牌区）
- 张小龙/马斯克主张 3 个元素（极致精简）
- 乔布斯折中：5 个板块但流动为一个整体

---

## 海报设计方案（4 个板块）

```
┌─────────────────────────────────┐
│                                 │
│         「主题句」               │  ← 15字以内，AI提炼
│      你这个月的底色               │     如："一直在撑，但假装没事"
│                                 │
│   ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─     │
│                                 │
│                                 │
│     "你日记中的一句原话"          │  ← 海报的灵魂，30字以内
│                                 │     精选本月最有力量的一句话
│                                 │     杂志大字排版，视觉重心
│                                 │
│   ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─     │
│                                 │
│     阿泓，六月快乐。              │  ← 昵称+月份，温暖锚定
│                                 │
│   ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─     │
│                                 │
│     小象一直在。                  │  ← 品牌签名，极小极淡
│                                 │
└─────────────────────────────────┘
```

### 板块 1：主题句（≤15字）

AI 从本月日记中提炼的元模式。不是概括，是一句让人心头一颤的话。

示例：
- "一直在撑，但假装没事"
- "嘴上说不在乎，日记里全是它"
- "从'应该'走向了'想要'"
- "这个月，你和自己和解了两次"

规则：
- 必须是用户本月日记支持的结论
- 不是鸡汤、不是建议、不是标签
- 脱离上下文后像一句歌词或诗

### 板块 2：日记原话金句（≤30字）

海报的灵魂。用户自己写的一句话，杂志大字排版。

选择标准（张小龙+蒂尔共识）：
1. 必须是用户原话，不做任何改写
2. 脱离上下文后有力量——像格言或歌词
3. 建构理想自我——用户看到会觉得"这就是我想成为的自己"
4. 不暴露隐私——朋友看到不会觉得尴尬
5. 不选极端低谷时的文字

示例（假设用户写了这些）：
- ✅ "我决定不再为别人的期待活着"
- ✅ "今天终于把那个拖了三个月的事做了"
- ✅ "原来勇敢不是不怕，是怕着还是往前走"
- ❌ "我好累好想辞职"（暴露隐私）
- ❌ "和男朋友又吵架了"（涉及他人）
- ❌ "今天心情一般"（没有力量）

### 板块 3：昵称+月份

"阿泓，六月快乐。"

规则：
- 昵称取用户设置的名字
- 月份用中文
- 语气：朋友发微信的感觉，不是系统通知

### 板块 4：品牌签名

"小象一直在。" 极小、极淡、角落。

不加：App下载链接、二维码、slogan。芒格说"海报不是广告位"。

## 视觉风格

### 色彩
- 每月一个主色调（12个预设，季节轮转）
- 背景大面积留白或淡色
- 金句用深色大字，是视觉重心
- 主题句用较小字号，浅色

### 字体
- 金句：衬线体（宋体/思源宋体），有温度、有重量
- 主题句：无衬线，轻盈
- 昵称：手写体或圆体，亲切
- 品牌签名：极小无衬线

### 排版
- 60% 留白
- 竖版，适合手机屏幕和朋友圈
- 金句占据海报 40% 的视觉面积
- 不做：卡通插画、渐变色、emoji、花边、勋章

### 小象 IP
- 角落极小的半透明小象轮廓
- 像藏书印，不是吉祥物
- 不说话、不举旗、不眨眼

### 尺寸
- 推荐：1080×1440（3:4，朋友圈最佳显示）
- 也支持 1080×1920（9:16，适合手机壁纸）

---

## 触发条件

- 本月日记 ≥ 8 篇才生成
- 在本月最后一篇日记的 Daily Echo 之后自然出现
- 提示文案：极淡灰色文字"这是你这个月的第 N 篇了。" 点击展开海报
- 不推送通知、不弹窗、不红点

## Prompt：金句选择

```
你是小象日志的「月度回声」模块。

## 输入
用户本月的所有日记文本（按日期排列）

## 任务
从日记中选择一句最有力量的原话，作为月度回声的金句。

## 选择标准
1. 必须是用户原话，一字不改
2. 脱离上下文后有力量——像格言或歌词
3. 用户看到会觉得"这确实是我说的，而且说得真好"
4. 不暴露隐私——朋友看到不会觉得尴尬
5. 不选涉及他人隐私的内容
6. 不选极端低谷时的文字（如想死、崩溃、恨某人）
7. 优先选择：认知突破、决定/决心、自我和解、温柔的观察

## 输出
只输出选中的原话，不要任何额外文字。
```

## Prompt：主题句生成

```
你是小象日志的「月度回声」模块。

## 输入
用户本月的所有日记文本
本月选中的金句：{quote}

## 任务
为这个月生成一句主题句（≤15字），作为月度回声海报的标题。

## 规则
1. 不是概括本月内容，是一句让人心头一颤的话
2. 必须有本月日记的证据支撑
3. 脱离上下文后像歌词或诗
4. 不是鸡汤、不是建议、不是标签
5. 不要出现"你"字——主题句是旁白，不是对用户说话

好的示例：
- "一直在撑，但假装没事"
- "嘴上不在乎，笔下全是它"
- "从'应该'走向了'想要'"
- "安静的月份，但不是空白的"

坏的示例：
- "本月你共写了23篇日记"（数据报告）
- "你是一个坚强的人"（标签）
- "继续保持加油"（鸡汤）

## 输出
只输出主题句，不要任何额外文字。
```

## 与问问大象的关键区别

| 维度 | 问问大象 | 小象日志 |
|------|---------|---------|
| 数据源 | 签到记录（行为） | 真实日记（心声） |
| 金句来源 | 系统生成的行为洞察 | 用户自己写的原话 |
| 板块数 | 6个（问候+成就+金句+特质+说明书+装饰） | 4个（主题句+金句+昵称+签名） |
| 核心冲击力 | "原来我是这样的人" | "原来我说过这样的话" |
| 分享动机 | 展示成就 | 展示自己 |
| 视觉风格 | 卡通可爱 | 杂志文艺 |

**一句话差异**：问问大象给用户一面镜子（你是什么样的人），小象日志给用户一封信（你说过这样的话）。

---

## 设计禁区（芒格检查清单）

1. ❌ 不展示情绪评分、心情指数、任何量化的情绪
2. ❌ 不展示"未写天数""最低谷那天"
3. ❌ 不贴人格标签（"内向""敏感""理性"）
4. ❌ 不展示涉及他人的内容
5. ❌ 不做成就系统（连续天数、满勤徽章）
6. ❌ 不加分享按钮（用户自己截图）
7. ❌ 不加App下载链接/二维码
8. ❌ 不在海报上做任何"建议"或"指导"
